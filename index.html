01

OneTap Capstone

Homeowners association management platform

Source Code

A web app we built as a team of 3 for our capstone. It helps homeowners association admins and officers manage their community — announcements, facilities reservations, issue reporting, and a lightweight violations tracker. We also added a chatbot so residents can find what they need without digging through menus. Separate dashboards for residents, officers, and admins.

PHP Laravel MySQL Tailwind CSS Livewire Leaflet.js
Under the hood
Role-Based Access

Three separate dashboards (resident, officer, admin) with middleware-based role gating so each user only sees what they're supposed to.

Real-Time Feel

Used Livewire for reactive UI updates — announcements, reservation statuses, and issue reports update without full page reloads.

Map Integration

Leaflet.js for community map views, letting officers pin and visualize reported issues by location within the subdivision.

02

Kilgi In Progress

Merchandising & accounting app for vegetable vendors

Source Code

An Android app I'm building for vegetable vendors who need a simple way to track their merchandise and money. You can batch-input purchases, log expenses and spoilages, then record end-of-day sales (retail or wholesale). It also tracks payables and receivables, and generates real accounting outputs — general journal, T-accounts, trial balance, income statement, owner's equity statement, and balance sheet.

Java Android Studio Jetpack Compose Room Database
Under the hood
Accounting Engine

Built a full double-entry bookkeeping system from scratch — general journal, T-accounts, and auto-generated trial balance and financial statements.

Data Layer

Room Database with structured DAOs for batch purchases, spoilage logs, sales records, and payables/receivables. All local, no internet needed.

UI

Jetpack Compose for a modern declarative UI. Batch input forms, daily sales summaries, and financial statement views — all native Android.
